Binary

Uses only 0 and 1. Computers represent data using binary states.

Octal

Base 8. Uses digits from 0 to 7.

Decimal

Base 10. The everyday number system, using 0 to 9.

Hexadecimal

Base 16. Uses 0 to 9 and A to F, where A means 10 and F means 15.
