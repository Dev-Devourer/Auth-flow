# Science Exhibition Presentation – AuthFlow & Logic Lab

Good morning respected teachers and judges. My project is listed as Logic Gates and Authentication. I call it AuthFlow and Logic Lab. It combines web development with digital electronics.
## Part 1: AuthFlow – Authentication Website

First, let me introduce AuthFlow.

AuthFlow is a website designed to demonstrate how user authentication works in modern websites.

When we visit websites, we often need to create an account or log in before accessing certain features. AuthFlow demonstrates this process.

For authentication, I have used **Supabase**. It manages user authentication, sessions and password recovery.

After successful authentication, users are redirected to their dashboard.

The dashboard welcomes the user and displays basic account information. It also provides a sign-out option.

I have also added a hamburger menu in the top-left corner. It opens a sidebar containing navigation links, information about the project and contact details.

For designing this website, I used HTML, CSS and JavaScript.

My website is hosted live on Vercel, and I can show it to you right now.

## Part 2: Logic Lab – Digital Logic and Number Systems

Now, Logic Lab. Every computer, phone and calculator runs on one idea: 0 and 1. Logic gates are the tiny decision-makers that work with those two values.

There are seven gates. I group them in three sets:

First, the basic three: AND, OR, NOT.
AND needs both inputs to be 1. OR needs at least one. NOT simply flips the input.

Second, their opposites: NAND and NOR.
NAND is AND flipped. NOR is OR flipped.

Third, the comparers: XOR and XNOR.
XOR gives 1 when the inputs are different. XNOR gives 1 when they are the same.

My project has a truth table for each gate and a live simulator. (Demo: click A = 1, B = 0 and say what changes.) You can see all seven gates react at once.

Number systems. Computers think in binary, but humans use other systems too. My converter handles binary, octal, decimal and hexadecimal. For example, 45 in decimal is 101101 in binary, 55 in octal and 2D in hexadecimal. (Demo: type 45 and show the other three.)

To sum up: AuthFlow shows how websites keep users secure. Logic Lab shows how computers think. Thank you!
