## Part 1: AuthFlow – Authentication Website

First, let me introduce AuthFlow.

AuthFlow is a website designed to demonstrate how user authentication works in modern websites.

When we visit websites, we often need to create an account or log in before accessing certain features. AuthFlow demonstrates this process.

My website includes:

1. **Sign-up:** New users can create an account using their name, email address and password.
2. **Email validation:** The website checks whether the email has a proper format, including an @ symbol and a dot in the domain.
3. **Show and hide password:** Users can choose whether to display or hide their password while typing.
4. **Login:** Existing users can sign in using their email and password.
5. **Google authentication:** Users can also sign in using their Google account.
6. **Forgot password:** Users can request a password reset link if they forget their password.

For authentication, I have used **Supabase**. It manages user authentication, sessions and password recovery.

After successful authentication, users are redirected to their dashboard.

The dashboard welcomes the user and displays basic account information. It also provides a sign-out option.

I have also added a hamburger menu in the top-left corner. It opens a sidebar containing navigation links, information about the project and contact details.

For designing this website, I used HTML, CSS and JavaScript.

I plan to use GitHub to maintain my project code and Vercel to host the website online.

## Part 2: Logic Lab – Digital Logic and Number Systems

Now, moving to the second part of my project.

Logic Lab is an educational section where we can understand the basics of digital electronics and number systems interactively.

Let us first understand logic gates.

Logic gates are the basic building blocks of digital electronic circuits. They perform logical operations using binary inputs, which are represented by 0 and 1.

There are seven basic gates demonstrated in my project:

- **AND Gate:** The output is 1 only when both inputs are 1.
- **OR Gate:** The output is 1 when at least one input is 1.
- **NOT Gate:** It reverses the input. If the input is 0, the output is 1, and vice versa.
- **NAND Gate:** It gives the opposite output of an AND gate.
- **NOR Gate:** It gives the opposite output of an OR gate.
- **XOR Gate:** Its output is 1 when the two inputs are different.
- **XNOR Gate:** Its output is 1 when both inputs are the same.

I have included truth tables for these gates.

There is also an interactive simulator where we can change two inputs, A and B, between 0 and 1 and observe how the outputs of the different gates change.

Now, let us move to number systems.

Computers use binary numbers to represent and process information. However, we also use other number systems to represent numbers in different ways.

My converter demonstrates four number systems:

1. **Binary:** Base 2, using digits 0 and 1.
2. **Octal:** Base 8, using digits 0 to 7.
3. **Decimal:** Base 10, using digits 0 to 9.
4. **Hexadecimal:** Base 16, using digits 0 to 9 and letters A to F.

For example, the decimal number 45 can be represented as:

- Binary: 101101
- Octal: 55
- Decimal: 45
- Hexadecimal: 2D

In my project, we can enter a number, select its original number system and instantly get its equivalent in the other three systems.

This makes understanding and practising number conversion easier.
