ABOUT THE PROJECT

Technology made easier to understand.

Welcome to AuthFlow! This website is an educational project created to demonstrate the fundamentals of web authentication and digital logic through interactive experiences. Our aim is to make learning technology practical, interesting and easier to understand.

Our Purpose

The main purpose of AuthFlow is to introduce visitors to the concepts behind modern websites and digital computing. Instead of only reading about these concepts, visitors can interact with the features and observe how they work. This project combines web development with basic computer science concepts in one place.

What Does This Website Offer?

AuthFlow brings together two educational components.

🔐

AuthFlow

An authentication demonstration that introduces how websites manage user accounts and access.

  • Email and password authentication
  • Google sign-in
  • Password recovery
  • Personalized dashboard
  • User session management
💡

Logic Lab

An interactive learning space for understanding digital logic and number systems.

  • Seven digital logic gates
  • Interactive gate simulations
  • Truth tables
  • Binary conversions
  • Octal, decimal and hexadecimal conversions
